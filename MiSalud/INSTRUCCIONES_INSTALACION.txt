MISALUD - PAQUETE UNIFICADO

ARCHIVOS NECESARIOS
- Carpeta MiSalud (la web completa)
- database/misalud.sql (UNICO archivo SQL para una base nueva o anterior)

INSTALACION EN XAMPP
1. Inicia Apache y MySQL desde XAMPP.
2. Haz una copia de tu carpeta anterior MiSalud antes de reemplazarla.
3. Si ya tienes datos, exporta una copia de seguridad de misalud_db
   desde phpMyAdmin antes de importar nada.
4. Copia la carpeta MiSalud descomprimida a C:\xampp\htdocs\MiSalud
   (debe existir C:\xampp\htdocs\MiSalud\index.php).
5. Visita http://localhost/phpmyadmin y usa IMPORTAR para seleccionar
   SOLAMENTE MiSalud/database/misalud.sql. El SQL crea misalud_db,
   las tablas que falten y añade columnas de expediente que aún falten;
   NO elimina pacientes, médicos ni citas ya guardados.
6. Revisa config/database.php; por defecto: servidor 127.0.0.1,
   base misalud_db, usuario root y contraseña vacía.
7. Abre http://localhost:80/MiSalud/index.php y pulsa Ctrl+F5.
8. Configura la primera cuenta admin si todavía no existe mediante
   setup_admin.php. Elimina este archivo después de usarlo.

EXPEDIENTE DEL PACIENTE
Se accede desde el perfil MEDICO > Mi agenda > Ver expediente del paciente
si existe una cita de ese paciente con el médico. Incluye fecha de nacimiento,
sexo, domicilio, contacto, ocupación y contacto de emergencia. La cédula del
médico aparece en Mi agenda y Mi perfil. No existe campo de grupo étnico.

IMPORTANTE
- Este paquete es para pruebas locales; no cargues expedientes clínicos reales
  sin auditoría de seguridad, consentimiento y controles de privacidad.
- Si aparece un error al IMPORTAR, copia el texto exacto del error de phpMyAdmin.
- Si ya tienes datos, NO borres la base de datos ni uses DROP TABLE.
